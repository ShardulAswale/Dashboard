# React Dashboard

React 18 and Material UI dashboard layout exercise built with Vite.

## How it works

Reusable components display navigation, summary cards, customer charts and a product sales table. Values are sample data defined in the components rather than live business metrics.

## Usage

Requires Node.js and npm. From the repository root:

```sh
npm install
npm run dev
```

Open the address printed by Vite. `npm run build` writes the static production files to `dist/`.

## Notes

No application backend is included. Some chart implementations and images are placeholders.
